Privacy Policy for ELNQYB

Last Updated: November 19, 2026

This Privacy Policy explains how ELNQYB (the "Bot") collects, uses, and protects data when you invite the Bot to a Discord server or interact with its commands and features.

1. Information We Collect

To operate properly, ELNQYB may temporarily process or store standard Discord identifiers and server configuration data, including:

  • Discord User IDs, Server (Guild) IDs, Channel IDs, and Role IDs.
  • Server settings and moderation configurations set by server administrators (such as blacklisted users, anti-spam rules, and protection logs).
  • Command inputs and interaction events necessary to execute requested features.

2. How We Use Information

The collected data is used strictly to:

  • Provide, maintain, and improve the Bot's security, moderation, and utility features.
  • Enforce server protection rules (such as anti-spam and blacklist actions) configured by server admins.
  • Troubleshoot bugs and prevent abuse or unauthorized activity.

3. Data Sharing and Third Parties

We do not sell, rent, or trade your data to third parties. Data is only processed through Discord's official API and the hosting infrastructure required to keep the Bot online.

4. Data Retention and Deletion

Server configuration data is retained only as long as the Bot remains in your server or is needed for its features to function. If you remove ELNQYB from your server or wish to request deletion of stored data, you can contact the developer directly.

5. Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Continued use of ELNQYB after changes are posted constitutes acceptance of the updated policy.

6. Contact

For privacy questions or data deletion requests, please contact the developer on Discord: .obq.
